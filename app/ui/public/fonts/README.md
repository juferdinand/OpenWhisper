# Bundled fonts

The renderer loads these fonts locally. It does not contact a font service.

- `InterVariable.woff2`: the existing setup font; license in `LICENSE.txt`.
- `InstrumentSans-Variable.ttf`: the reference interface font, copied without
  modification from [google/fonts at 0b58fb3](https://github.com/google/fonts/blob/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/instrumentsans/InstrumentSans%5Bwdth%2Cwght%5D.ttf).
  License: `InstrumentSans-OFL.txt`.
  SHA-256: `b24f1812584816958afcf22e22d08e44318c5e51651e25d2438efdde389b33b1`.
- `Newsreader-Variable.ttf`: the reference transcript font, copied without
  modification from [google/fonts at 8b0a1d0](https://github.com/google/fonts/blob/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/newsreader/Newsreader%5Bopsz%2Cwght%5D.ttf).
  License: `Newsreader-OFL.txt`.
  SHA-256: `8a08d13f8a6c0d51be379a60af84f945f65369a67e509ee3c3bdcc421254d7c1`.

The application package retains this directory, including the license files.
